# 40 Shades Advertising Dashboard

A GitHub Pages dashboard for the UK Amazon Ads campaigns for *40 Shades of Teaching Hell* and *40 Shades of Corporate Misery*.

Data is refreshed by a scheduled GitHub Actions workflow using Windsor.ai. Keep the Windsor API key in the repository Actions secret `WINDSOR_API_KEY`; never commit it or paste it into the dashboard.

Public GitHub Pages site: advertising figures published here will be public.
